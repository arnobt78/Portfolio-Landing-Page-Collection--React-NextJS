# Contributing

Each `portfolio-ui-design-N` directory is an independent project. Keep changes scoped to the affected application and follow its existing conventions, scripts, and documentation. Preserve its lockfile, assets, attribution, and deployment configuration.

Install dependencies with `npm ci` inside the project. Do not introduce shared dependencies or upgrade unrelated packages as part of a focused change. Run the project's available lint, build, and tests, and describe any checks that could not run.

For a pull request, explain the change, list affected projects and verification, and include screenshots for visual changes where useful. Update relevant documentation and environment templates without adding credentials. Read [SECURITY.md](SECURITY.md) before reporting a vulnerability.
