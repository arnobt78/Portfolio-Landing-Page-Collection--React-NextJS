# Security policy

This policy covers the collection and its individual portfolio projects. Do not include credentials, private environment files, or sensitive personal data in commits, logs, issues, or pull requests. Public client-side environment variables are visible to visitors and must not contain secrets.

To report a vulnerability, use the repository's private vulnerability reporting feature if enabled, or contact the repository maintainer privately through their GitHub profile. Do not publish exploit details until the maintainer has had an opportunity to investigate. Include the affected project, impact, and safe reproduction steps.

Review dependency advisories for affected projects and validate updates before applying them. No response or remediation timeline is guaranteed.
